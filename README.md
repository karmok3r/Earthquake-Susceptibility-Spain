# Earthquake Susceptibility Analysis - Spain

## Visualization
![Earthquake Susceptibility Map](https://github.com/karmok3r/Earthquake-Susceptibility-Spain/raw/main/Earthquake%20Susceptibility%20Analysis.jpg)

## Overview
This project presents a geospatial analysis of earthquake susceptibility across Spain. By integrating historical seismic data and geological factors, the visualization identifies regions with varying levels of earthquake risk, ranging from low to very high susceptibility.
